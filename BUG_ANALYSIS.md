# Анализ трёх багов в index-navi.html

## Баг 1: Только "Продаю" отображается в профиле

**Проблема:** В профиле пользователя видна только категория "Продаю", остальные категории (Куплю, Услуги, Отдам даром) не видны.

**Диагностика:**
- Категории инициализируются правильно (строка 1512): `["all", "sell", "buy", "services", "free"]`
- В AdminTab (админ-панель) на строке 8447-8451 есть `catLabel` со всеми 4 категориями
- Логика фильтрации правильная (строка 1532): `if (a.category === "free" || !a.price) return priceMin === 0;`

**Гипотеза:** Объявления с категориями "buy", "services", "free" не загружаются в localStorage, или фильтруются при инициализации.

**Место в коде:** AdminTab, строки 8432-8500 (рендер объявлений пользователя)

---

## Баг 2: 8-значный PIN не работает

**Проблема:** 
- Последняя (8-я) цифра не исчезает после ввода
- Поля сдвигаются при вводе
- Кнопка "Войти" не реагирует

**Диагностика:**
- Компонент PinRow (строка 5428-5451) правильно обрабатывает ввод
- Функция changePin (строка 5287-5295) корректна: `n[i] = val.slice(-1);`
- На строке 5293 фокус остаётся на последнем поле: `if (val && i < arr.length - 1) refs[i + 1].current.focus();`
- CSS для `.code-digit` (строка 159) выглядит нормально

**Гипотеза:** Проблема в CSS — поля сдвигаются из-за появления клавиатуры на мобильном. Возможно, нужно добавить `position: fixed` или `viewport-fit: cover`.

**Место в коде:**
- PinRow: строка 5428
- changePin: строка 5287
- CSS: строка 159

## Баг 3: Дублирующиеся кнопки категорий на главной

**Проблема:** На главной странице две одинаковые кнопки для "Продаж" и "Услуг".

**Диагностика:**
- Кнопки категорий рендерятся на строке 1655: `cats.map(function (c) { ... })`
- Массив категорий: `["all", "sell", "buy", "services", "free"]` (5 элементов)
- Также есть другие места где рендерятся категории: строки 2867, 2882

**Гипотеза:** Возможно, категории рендерятся дважды в разных местах, или есть дублирующийся код.

**Место в коде:** 
- Строка 1655 (основной рендер)
- Строки 2867, 2882 (возможные дубликаты)

## Рекомендации по исправлению

1. **Баг 1:** Проверить логику загрузки объявлений в localStorage при инициализации. Убедиться что все категории загружаются.

2. **Баг 2:** Добавить CSS для фиксирования позиции PIN полей при появлении клавиатуры.

3. **Баг 3:** Проверить строки 2867, 2882 — возможно там дублируется рендер категорий.
